A faster drop-in for make.fun's csv-reader 1.0.0 in plain JavaScript: `solve.js` reads each CSV text in one pass over
char codes, cutting fields with `slice()` instead of building them a character at a time, and answers exactly the
reference's `{columns, rows, errors}` (quotes, stray CRs, quote junk, unterminated quotes, short and long rows).

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
